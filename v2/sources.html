How sources are checked

  • Each source is downloaded automatically every month, and its data period and retrieval date are recorded.
  • Data is matched to towns by official ID, never by name. New Jersey has many towns with the same name.
  • Before anything is published, checks confirm that all 564 towns are present, that values are plausible, and that the data's format hasn't changed. If a check fails, the previous data stays up.
  • Each source's terms of use were checked before using it. Sources whose terms don't allow republishing are not shown.
