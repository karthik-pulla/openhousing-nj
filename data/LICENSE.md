credit OpenHousing NJ and note any changes.

**Source data keeps its own terms.** The underlying figures come from public
sources, each with its own conditions. Credit them too:

| Source | Terms |
|---|---|
| U.S. Census Bureau, American Community Survey | U.S. government work, public domain |
| NJ Department of Community Affairs (property tax tables, Fourth Round obligations) | New Jersey public government data |
| HUD USER API (income limits, Fair Market Rents) | Free to use; must display: "This product uses the HUD User Data API but is not endorsed or certified by HUD User." |
| Freddie Mac Primary Mortgage Market Survey, via FRED | Copyright Freddie Mac, used with attribution; must display: "This product uses the FRED® API but is not endorsed or certified by the Federal Reserve Bank of St. Louis." |
| National Zoning and Land Use Database (Mleczko & Desmond, 2023) | Published openly by the authors; cite: Mleczko, Matthew, and Matthew Desmond. 2023. National Zoning and Land Use Database. https://github.com/mtmleczko/nzlud |
| NJOGIS municipal boundaries | New Jersey open data |

Zillow and Redfin data are not included (see docs/SOURCES_VERIFICATION.md).

## How to cite

> OpenHousing NJ. *OpenHousing NJ dataset*, release YYYY-MM-DD. https://github.com/karthik-pulla/nj-housing-index

Use the release date of the file you downloaded (it is in `data/manifest.json`
as `published_at`, and every release is kept in `data/archive/releases/`).
